# Protokol — интерфейс совещаний

Интерфейс проводит пользователя от загрузки записи до подтверждённого протокола:
показывает распознавание и говорящих, журнал действий агента, поручения с цитатами,
предупреждения проверки и экспорт PDF/DOCX. Реестр поручений хранит отметки
«в работе» / «выполнено» в браузере и вычисляет просрочку по локальной дате.

## Запуск

Нужны Node.js 22+ и pnpm 11. Из каталога `frontend/`:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть `http://localhost:5173/#/app`. По умолчанию `/api` проксируется на
`http://localhost:8000`. Для backend на другом компьютере в доверенной сети:

```sh
API_TARGET=http://<адрес-ноутбука>:8000 pnpm dev
```

Backend должен быть запущен с `--host 0.0.0.0`. Браузер обращается к Vite;
аудио передаётся на указанный backend. Это не обработка внутри браузера.
Не задавайте внешний облачный endpoint для конфиденциальных записей.
Адрес backend не зафиксирован в исходниках. Для производственной сборки:

```sh
pnpm build
```

Dockerfile собирает статику и обслуживает её через nginx; `/api` направляется
в сервис `api:8000`. Лимит запроса nginx — 300 MiB (с учётом multipart-обёртки),
backend отдельно проверяет размер файла. Внешних шрифтов, CDN и аналитики нет.

## Проверка на настоящем backend

1. Загрузить непустой MP3/WAV/M4A/MP4/OGG/WEBM/FLAC до 300 MiB. Указать
   фактическую дату встречи: она используется для относительных сроков.
2. Новая встреча появляется слева без перезагрузки. Нажать «Транскрибировать»;
   интерфейс опрашивает состояние каждые 2 секунды. Дождаться готовности или
   прочитать причину ошибки. Числовой процент обработки сервер не предоставляет.
3. Проверить реплики, таймкоды и языки. При необходимости раскрыть «Говорящие»
   и сохранить имя по Enter, при выходе из поля или кнопкой.
4. Сформировать протокол. Кнопка доступна только после распознавания. В журнале
   видны вызовы инструментов; нажатие на поручение показывает цитаты и выделяет
   первую связанную реплику. `owner_name` — исполнитель, `owner_speaker_id` —
   тот, кто дал поручение. Эти люди могут различаться.
5. Проверить предупреждения, отметить их просмотр и подтвердить протокол.
   После сохранения скачать PDF и DOCX; открыть документы и проверить содержимое.
6. Изменить статус поручения, обновить страницу и проверить сохранение в браузере.
   Просроченный срок не делает выполненное поручение просроченным.

## Автоматические проверки

```sh
pnpm test
pnpm lint
pnpm build
```

Проверяются, в частности: multipart-загрузка и ошибки API, различие исполнителя
и автора поручения, ссылки на реплики, polling и его остановка, переименование,
доступность загрузки на пустом экране, обновление списка, запрет запуска до
готовности стенограммы, подтверждение при потере SSE и локальные статусы.

Для браузерных проверок:

```sh
pnpm exec playwright install chromium
pnpm test:e2e
# Либо при уже установленном Google Chrome:
PLAYWRIGHT_CHANNEL=chrome pnpm test:e2e
```

Playwright сам запускает Vite. Тесты используют **имитацию HTTP-ответов** и
синтетические данные из `src/test/fixtures.ts`. Проверяют интерфейс в браузере,
включая загрузку, распознавание → подтверждение → ссылки экспорта, узкий экран и
отсутствие внешних запросов. Они не проверяют модели, реальный экспорт документов
или точность распознавания. Скриншоты сохраняются в игнорируемый `test-results/`.
Для своего dev-сервера задайте `E2E_BASE_URL`.

## Что учитывать при демонстрации

- До подтверждения экспорт недоступен. После подтверждения повторная
  транскрибация блокируется backend, чтобы сохранить ссылки на реплики.
- Изменение имён после формирования проекта требует повторного анализа:
  backend отклоняет подтверждение устаревшего проекта.
- Изменение сроков/текста поручений API пока не поддерживает. Статусы локальные,
  не синхронизируются с сервером и не меняют PDF/DOCX. При запрете localStorage
  интерфейс предупреждает, что отметки сохранятся только до закрытия страницы.
- Протокол без поручений допустим: саммари и решения доступны для экспорта.
- Индикатор сети показывает `provenance.enabled` и **заблокированные попытки**,
  а не число успешных внешних соединений. `scripted:*` помечается как
  демонстрационный режим; отсутствие моделей показывается отдельно.
- Главное окно показывает первые 300 реплик; для остальных выводится счётчик.
  Цитата поручения разрешается по полной полученной стенограмме.
- API пока не предоставляет URL воспроизведения записи и редактирование
  протокола. Серверный `audio_path` не показывается пользователю как аудиоссылка.
