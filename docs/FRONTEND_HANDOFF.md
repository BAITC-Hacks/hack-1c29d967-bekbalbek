# Интерфейс Protokol

Актуальные поля встречи, стенограммы, предложений и подтверждения описаны в [API.md](API.md), последовательность обработки — в [ARCHITECTURE.md](ARCHITECTURE.md).

`owner_name` обозначает исполнителя, `owner_speaker_id` — поручившего. Для цитаты используется `source_segment_ids` и `segment:<id>`. Кнопки экспорта обращаются к подтверждённому протоколу; до подтверждения сервер возвращает 404.

Docker использует `scripted:auto`; полноценная генерация Qwen описана в [LOCAL_LLM.md](LOCAL_LLM.md) и запускается на хосте. Список примеров API включает загруженные встречи. Переименование говорящего поддержано через PATCH; API редактирования поручений и их статусов пока нет.
